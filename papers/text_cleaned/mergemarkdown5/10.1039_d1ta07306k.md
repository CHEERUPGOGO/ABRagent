# Results and discussion  Expected growth pictures of lithium metal deposit were compared between copper foil, low-loading-lithiophile 3D scaffold $\left( \mathbf { A } \mathbf { g } _ { 1 . 3 } @ \mathbf { C } \right)$ and heavy-loading-lithiophile 3D scaffold $\left( \mathsf { } _ { 1 4 } @ \mathsf { } \right)$ (Fig. 1). As reported in literature, 2D electrodes (e.g., copper foil) failed to discourage current to be localized so that lithium metal nucleation was unevenly distributed, and lithium dendrites were grown extensively (Fig. 1a).8 In the 3D scaffold electrodes, on the other hand, the plating current ux was distributed over their high surface area while the compartmented space in their porous structure limited the dendritic growth of lithium metal. When a lithiophile (e.g., silver) was loaded on the 3D scaffold, the lithium affinity of the lithiophile drove the internal surface of the 3D scaffold to be more efficiently utilized for lithium metal plating $\mathbf { \left( _ { 1 . 3 } @ C \right. }$ in Fig. 1b). The silver metal lithiophile was lithiated to form silver–lithium alloy $( \mathtt { } _ { x } \mathtt { } _ { y }$ as the secondary lithophile) before lithium metal plating. The lithiophilic alloy encouraged the lithium metal to be plated at a smaller nucleation overpotential. Aer all of the lithiophilic sites were devoted to nucleating lithium metal and therefore totally covered by the lithium metal, the internal space of the 3D scaffold was not preferred for metal plating any more in the absence of the fresh surface of silver. Lithium metal began to be deposited on the external topmost surface of the scaffold and then grew dendritically, leaving the silver-absent internal surface partially intact. Heavier loading of the lithiophile was required to utilize the whole area and volume of the internal space for lithium metal plating $\left( \mathbf { _ { 1 4 } } @ \mathbf { } \right.$ in Fig. 1c). A 3D scaffold having silver nanoparticles heavily loaded on carbon frame was prepared by the solution–ltration–calcination process in the presence of melamine as an argentophile (Fig. 2a). When melamine was mixed with graphene oxide (GO) and carbon nanotube (CNT) as the scaffold-building blocks, the argentophile (melamine) was bound to the carboxyl group of GO (Mel@GO/CNT in the le of Fig. 2a). The presence of melamine signicantly reduced the infrared intensity of the peak for the carboxyl group of GO at $1 7 2 0 ~ \mathrm { } ^ { - 1 }$ (Mel@GO/CNT versus GO/ CNT in Fig. 2b and ${ \bf S } 2 \dagger { \bf \Sigma }$ ).26–30 When the silver precursor was introduced into the Mel@GO/CNT-containing solution, ${ \mathbf { A } } { \mathbf { g } } ^ { + }$ was bound to the pyridinic nitrogen of melamine $\left( \mathbf { - } ^ { + } @ \mathbf { } / \right.$ CNT in the center of Fig. 2a). The interaction between ${ \mathbf { A } } { \mathbf { g } } ^ { + }$ and pyridinic nitrogen $( \mathsf { } ^ { + } \mathrm { - } \mathsf { } )$ was clearly conrmed by the infrared peak shi of $\mathbf { N - C = N }$ of melamine from $1 4 3 0 ~ \mathrm { } ^ { - 1 }$ to $1 3 5 7 ~ \mathrm { } ^ { - 1 }$ (from Mel to $\mathrm { \mathbf { - } ^ { + } }$ in Fig. 2b and ${ \bf S } 2 \dagger$ ).31,32 The strong ${ \mathbf { A } } { \mathbf { g } } ^ { + } .$ –pN interaction was also conrmed by identifying the molecular fragment of $\mathbf { } ^ { + }$ in the time-of-ight secondary ion mass spectroscopic (TOF-SIMS) spectra. The peak for the AgN+ fragment was clearly shown in the melamine-containing sample $( \mathrm { - ^ { + } ( \bar { \ a } / }$ in Fig. 2c), which was contrasted with the absence of the peak for the melamine-absent counterpart $\left( \mathbf { } ^ { + } @ \mathbf { } / \mathbf { } \right)$ . Moreover, the $\mathbf { } ^ { + }$ signal was found over the whole body of the melamine-containing lm (Fig. 2d). Therefore, it was evident that the silver lithiophile precursor $\left( \mathrm { } ^ { + } \right)$ was strongly bound to the pyridinic-nitrogen-containing argentophile before calcination. Aer the lm assembly via vacuum ltration followed by calcination, the silver cation bound to the pyridinic nitrogen was reduced to silver metal nanoparticles. At the same time, the GO was converted to reduced graphene oxide (rGO) while the scaffold building blocks (rGO/CNT) were partially nitrogendoped by melamine $\left( \mathbf { _ { 1 4 } } @ \mathbf { } \right.$ in the right of Fig. 2a; NC for nitrogen-doped carbon scaffold-building blocks). The nitrogen doping of the carbon matrix of $\mathrm { _ { 1 4 } @ }$ was conrmed by the X-ray photoelectron spectroscopy (XPS) N1s spectra. The pyridinic and graphitic nitrogen were found at 398.3 and $4 0 0 ~ \mathrm { }$ respectively in $\mathrm { _ { 1 4 } @ }$ while there was no nitrogen signal for $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ (Fig. 3a).33 The nitrogen doping level of the carbon matrix (NC) of $\mathrm { _ { 1 4 } @ }$ was $1 4 ~ \mathrm { ^ { 0 } / o }$ , which was measured by the elemental analysis based on combustion. There was every possibility that the pyridinic and graphitic nitrogen played the role of lithiophilic sites.34–36 The $3 \mathrm { d } _ { 5 / 2 }$ and $3 \mathrm { d } _ { 3 / 2 }$ peaks of the XPS Ag3d spectra conrmed that silver was successfully embedded in both the 3D scaffolds $\left( \mathbf { _ { 1 4 } } @ \mathbf { } \right.$ and $\mathbf { } _ { 1 . 3 } @ \mathbf { C } )$ (Fig. S3†).37 The loading amount of silver in $\mathrm { _ { 1 4 } @ }$ was ten times higher than that of $\mathrm { } _ { 1 . 3 } ( \textcircled { \mathrm { 2 } } \mathrm { C }$ (14 $\mathrm { \% } ~ = ~ 5 0 ~ \mathrm { \% }$ for $\mathrm { _ { 1 4 } @ }$ versus $1 . 3 \ \mathrm { \% } \ = \ 1 0 \ \mathrm { \% }$ for $\mathbf { } _ { 1 . 3 } @ \mathbf { C } )$ , which were quantied by the inductively coupled plasma-optical emission spectrometry (ICP-OES) (Fig. ${ \bf S } 4 \dagger .$ ). Similarly, the ${ \mathbf { A } } { \mathbf { g } } ^ { + }$ TOF-SIMS signal of $\mathrm { _ { 1 4 } @ }$ was 14 times higher than that of $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ along the whole depth prole (Fig. 3b). Silver was more densely distributed in $\mathrm { _ { 1 4 } @ }$ when compared with $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ , which was clearly visualized by three-dimensional ${ \mathbf { A } } { \mathbf { g } } ^ { + }$ TOF-SIMS images (Fig. S6†) and EDS silver mapping (Fig. ${ \bf S 7 \dagger }$ ). The more uniform distribution of silver in the NC matrix was derived from the strong ${ \mathbf { A } } { \mathbf { g } } ^ { + } .$ –pN interaction that could prevent agglomeration of silver. The interaction between silver and nitrogen survived aer calcination following ltration. The $\mathbf { } ^ { + }$ signal indicating the interaction between the silver metal and the nitrogen doped in carbon scaffold was detected in $\mathrm { _ { 1 4 } @ }$ by TOF-SIMS (Fig. S9†). The Ag–N interaction of $\mathrm { _ { 1 4 } @ }$ aer calcination was thought to be inherited from the $\mathsf { ^ { + } { - } }$ interaction of the $\mathbf { - ^ { + } ( \bar { a } / }$ before calcination. The electronic state of the silver loaded on 3D scaffolds was investigated by X-ray absorption near edge structure (XANES) spectra of the Ag Kedge (Fig. 3c). When the silver was placed as a form of nanoscale particle or island on the carbon substrates, the spectral edges of $\mathrm { } _ { 1 4 } \textcircled { \mathrm { 2 } } \mathrm { }$ and $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ were blue-shied from Ag foil toward $\mathbf { } _ { 2 } \mathbf { O }$ . Therefore, the oxidation number of silver loaded on the 3D scaffolds was estimated between that of Ag metal (0) and $\mathbf { } _ { 2 } \mathbf { O }$ $\left( + 1 \right)$ . Such a biased distribution of electron density from metal to neighboring atoms and/or support materials has oen been reported in literature.38–43 The extended X-ray absorption ne structure (EXAFS) spectroscopy conrmed the Ag–N interaction of $\mathrm { _ { 1 4 } @ }$ by investigating the neighboring environment of the silver loaded on 3D scaffolds (Fourier-transformed $k ^ { 3 }$ -weighted EXAFS spectra in radial distribution function (RDF) in Fig. 3d). The intensity of the Ag–Ag peak at $2 . 8 \mathrm { ~ \AA ~ }$ decreased along Ag foil to $\mathrm { } _ { 1 . 3 } ( \textcircled { \mathrm { 2 } } \mathrm { C }$ to $\mathrm { _ { 1 4 } @ }$ . Based on the knowledge that the $\mathbf { - }$ peak intensity is proportional to the average number of silver atoms neighboring a single silver atom, it was easily understood that the Ag–Ag peak intensities of the 3D scaffolds were smaller than that of the Ag foil. Only the Ag–Ag bonds were available in Ag foil while the Ag–C and/or Ag–N bonds were found at the interface between silver nanoparticles and carbon or nitrogendoped carbon framework. The Ag–Ag intensity of $\mathrm { _ { 1 4 } @ }$ lower than that of $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ indicated that the interfacial area between silver nanoparticles and carbon frame in $\mathbf { _ { 1 4 } } \textcircled { \mathbf { 2 } }$ was larger than that of $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ . The argentophilicity of the surface of the nitrogen-doped carbon framework of $\mathrm { _ { 1 4 } @ }$ based on the strong Ag–N interaction spread the silver mass over the surface of its internal porous structure, bringing more nitrogen and carbon atoms into the rst shell of silver atoms.

The introduction of melamine to the precursor solution made the 3D scaffold electrodes thicker aer ltration followed by calcination. The $\mathrm { _ { 1 4 } @ }$ electrode was expected to be 1.36 times thicker than the $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ when the volume was calculated from the mass of the ingredients and their true densities. The measured thickness of $\mathrm { _ { 1 4 } @ }$ relative to $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ was thicker than the expected value, suggesting that the presence of melamine in the precursor solution made the 3D architecture more porous aer calcination. The thickness of the $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ scaffold electrode was estimated to be $4 5 ~ { \mu \mathrm { m } }$ while the $\mathrm { _ { 1 4 } @ }$ electrode prepared with the additional melamine mass was $1 0 0 \mu \mathrm { m } \cdot$ - thick (Fig. 3e and f). Macroscopic voids were clearly found in the electron-microscopic image of $\mathbf { _ { 1 4 } } \mathbf { \textcircled { 2 } }$ (Fig. 3e) while graphene and CNT were more densely packed in $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ (Fig. 3f). The molecular complex of ${ \mathbf { A } } { \mathbf { g } } ^ { + }$ and melamine in the precursor solution for $\mathrm { _ { 1 4 } @ }$ possibly hindered the $\pi - \pi$ stacking of the GO plates during ltration, discouraging the carbon building blocks to be densely packed.44–46 The porous structure allowed the $\mathrm { _ { 1 4 } @ }$ to have larger electrochemically effective surface area when compared with the densely packed $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ . The electric double layer capacitance was used as a measure of the electrochemically effective surface area, which was measured in the potential region not involving faradaic reactions such as lithiation or lithium plating (Fig. ${ \bf S 1 0 \dagger }$ ). A copper foil as the nonporous conductive electrode had the area equivalent to 0.4 $\mathrm { } ^ { - 2 }$ . The $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ was eight times as porous as the copper foil in terms of surface area $\left( 3 \mathrm { } \mathrm { } ^ { - 2 } \right)$ ) even if the constituent carbon building blocks appeared to be densely packed. The internal voids of the $\mathrm { _ { 1 4 } @ }$ provided the largest area (20 mF $\mathrm { } ^ { - 2 }$ ), which was 50 times larger than the copper foil and 7 times larger than the $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ .

Lithium plating electrochemistry was investigated by plating lithium metal on the 3D or 2D electrode in the cells employing $\mathrm { _ { 1 4 } @ }$ , $\mathrm { } _ { 1 . 3 } ( \textcircled { \mathrm { 2 } } \mathrm { C }$ or copper foil as the working electrode with lithium metal counter electrode $\left( \mathbf { _ { 1 4 } } @ \mathbf { } \right\|$ Li, $\mathbf { } _ { 1 . 3 } ( \mathbf { \widehat { a } } ) \mathbf { C } \| \mathbf { }$ and $\mathbf { } \lVert \mathbf { }$ in Fig. 4a). Prior to the lithium metal plating, two electrochemical reactions were expected to proceed: (1) the electrolyte decomposition to form the solid-electrolyte interphase (SEI) layer and (2) the silver–lithium alloying.47 The processes were clearly identied in the potential prole of the $\mathrm { _ { 1 4 } @ }$ having high surface area and heavy silver loading (Fig. S11†): the SEI layer formation based on electrolyte decomposition from 1.7 to $0 . 1 ~ \mathrm { V _ { / ^ { + } } }$ followed by the faradaic plateau responsible for the silver–lithium alloying reaction from 0.085 to 0.03 $\mathrm { V _ { / ^ { + } } }$ . 48 At the beginning of lithium plating below $0 \mathrm { V _ { / ^ { + } } }$ , the largest overpotential was required for nucleating lithium metal (Fig. 4a). The overpotentials for the subsequent metal plating decreased once the lithium metal nuclei were formed. The nucleation overpotentials $\textstyle \mu _ { \mathrm { n } } =$ the saturated plating voltage – the minimum voltage for nucleation) were compared between $\mathbf { _ { 1 4 } } \textcircled { \mathbf { 2 } }$ , $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ and copper foil (Cu). Even if the lithiophile content was focused as the factor to improve the nucleation kinetics, the void-containing structure to provide high surface area for plating and large volume to accommodate metal deposit should be considered as one of the main factors to improve the cycling durability as well as the kinetics. The morphology of lithium metal deposit plated on the 3D scaffolds was compared between $\mathrm { _ { 1 4 } ( \overline { { { \bf a } } } }$ and $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ by scanning electron microscopy (SEM) (Fig. 5). When 1 mA h $\mathrm { } ^ { - 2 }$ of lithium metal was plated at $1 \ \mathrm { } \ \mathrm { } ^ { - 2 }$ , the deposit volume was totally accommodated by the 3D scaffold having the heavy loading of the lithiophile $\mathbf { \widetilde { _ { 1 4 } } } \mathbf { \widetilde { } }$ in Fig. 5a and b). Lithium metal was evenly and compactly plated on both sides of the laminae of the layered carbon frame. The empty space in the internal volume of $\mathrm { _ { 1 4 } ( \overline { { { \bf a } } } ) }$ was available for additional lithium metal plating. Any dendritic feature was not found in the lithium metal deposit of $\mathrm { _ { 1 4 } ( \overline { { { \bf a } } } }$ . This even deposition characteristics was contrasted with the dendritic feature of lithium metal plated on the less-lithiophile 3D scaffold $\mathbf { \left( _ { 1 . 3 } @ C \right. }$ in Fig. 5e and f). The lithium metal dendrites were tens-of-nm-thick, which were much thinner than $1 \mu \mathrm { m }$ -thick dendrites randomly grown on 2D copper foil in the absence of the lithiophile (Fig. S16†). The $1 \mathrm { } ^ { - 2 }$ deposit volume was not accommodated by the compact $\mathrm { } _ { 1 . 3 } ( \textcircled { \mathrm { 2 } } \mathrm { C }$ scaffold so that shiny lithium metal deposited on the outer surface of the electrode was recognized by naked eyes (the inset of Fig. 5e).

On the other hand, the metal deposit overowed from the structure of the $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ scaffold electrode to the external surface (Fig. 5g and h). More amount of lithium metal deposit was found on the edge of the electrode where the current density was concentrated (the inset of Fig. 5g).49,50 The growth of lithium metal plated over the external surface of the 3D scaffold was not regulated since the lithiophile existing inside of the scaffold did not affect the metal growth. The 3D scaffolds were infused with lithium metal for building lithium metal batteries. The silver embedded in the 3D scaffolds was alloyed with molten lithium metal. The lithiophilicity of the lithium–silver alloy facilitated the infusion of lithium metal into the internal space of the 3D scaffolds. The Xray diffraction (XRD) pattern clearly showed that the characteristic silver peaks of $\mathrm { _ { 1 4 } @ }$ and $\mathrm { } _ { 1 . 3 } ( \textcircled { \mathrm { 2 } } \mathrm { C }$ completely disappeared aer lithium infusion, while the $\mathbf { } _ { x } \mathbf { } _ { y }$ alloy and lithium metal peaks were developed in $\mathrm { } _ { 1 4 } @ \mathrm { }$ and $\mathrm { } _ { 1 . 3 } @ \mathrm { C }$ (Fig. S18†).51–55 The electrode thickness increased slightly aer lithium infusion from 100 to $1 1 5 \mu \mathrm { m }$ for $\mathrm { _ { 1 4 } @ }$ and 45 to $6 0 ~ { \mu \mathrm { m } }$ for $\mathrm { } _ { 1 . 3 } ( \textcircled { \mathrm { 2 } } \mathrm { C }$ due to the swelling of the 3D scaffolds and/or the excess layer of lithium metal above the 3D scaffolds (Fig. S19a and b†). The amount of lithium metal loaded in the 3D scaffolds in $0 . 7 8 5 ~ \mathrm { } ^ { 2 }$ was $1 4 \mathrm { \ }$ h for $\mathrm { _ { 1 4 } @ }$ and 6.7 mA h for $\mathrm { } _ { 1 . 3 } ( \widehat { \mathrm { a } } \mathrm { C }$ (Fig. S19c†). This capacity of $\mathrm { } _ { 1 4 } \textcircled { \mathrm { 2 } } \mathrm { }$ was slightly smaller than that of $1 0 0 ~ { \mu \mathrm { m } }$ -thick lithium metal foil in the same area (16.8 mA h).

Lithium metal electrode of LOBs was placed in a harsh environment where oxygen fuel and water impurity in electrolytes were reacted with lithium metal.56 Capacity of the LOB cells having the lithium-infused 3D scaffold anodes was monitored when the cells were discharged and charged repeatedly at $0 . 2 \mathrm { \ } \mathrm { \ } ^ { - 2 }$ up to $0 . 2 \mathrm { \ } \mathrm { ~ h ~ } ^ { - 2 }$ (Fig. 6d and e). The xed capacity at 0.2 mA h $\mathrm { } ^ { - 2 }$ was extracted up to the $7 3 ^ { \mathrm { } }$ and $5 3 ^ { \mathrm { } }$ cycle from the LOB cells having lithium metal $\mathrm { ( _ { 0 } ) }$ and $\mathrm { } _ { 1 . 3 } @ \mathrm { C }$ anodes, respectively. Then, the oxygen cathodes of the LOB cells were replaced by fresh carbon electrodes aer the serious capacity decay was met. The LOB cells did not work with the fresh carbon electrodes, indicating that the capacity decay was caused not by the air cathode but by the lithium anode. The lithium metal source in the lithium metal $\mathrm { ( _ { 0 } ) }$ and $\mathrm { } _ { 1 . 3 } @ \mathrm { C }$ would be totally consumed by side reactions including electrolyte decomposition and oxygen-triggering oxidation reaction.56 The LOB cells having the lithium-infused highest-lithiophile-loading 3D scaffold $\left( \mathrm { } _ { 1 4 } @ \mathrm { } \right)$ anode, on the other hand, showed the best cycling durability up to the $1 1 2 ^ { \mathrm { } }$ cycle. More interestingly, the LOB cell operation was successfully extended when the air cathode was replaced with a fresh carbon electrode. It indicated that the cycling durability was limited not by the 3D scaffold anode but by the air cathode. Carbon cathode of LOBs was not efficiently utilized for oxygen reduction reaction as the discharge product $\left( \mathrm { } _ { 2 } \mathbf { O } _ { 2 } \right)$ as well as by-products (e.g., $\mathbf { } _ { 2 } \mathbf { } _ { 3 }$ , LiOH, $\operatorname { } _ { 3 }$ and LiCOOR) was accumulated on its surface.57 When considering that the lithium storage capacity was similar or identical between $1 0 0 \mu \mathrm { m }$ -thick lithium metal and $1 1 5 \mu \mathrm { m }$ -thick $\mathrm { } _ { 1 4 } @ \mathrm { }$ scaffolds, the most durable initial cyclability and its extension by the cathode replacement supported that the 3D carbon-framed architecture of the $\mathrm { } _ { 1 4 }$ scaffold improved the lithium metal plating/stripping reversibility. Therefore, our high-loading-lithiophile 3D scaffold-based full cells demonstrated incomparable capacity retention to the previous performances of the full cells having3D-structured lithium anode under intense cycling conditions (Table S1†).

In this study, we realized the effective three-dimensional carbon-framed scaffold having heavily loaded lithiophiles (silver) for lithium metal anode. The argentophilic (silver-philic) melamine contributed to the heavy embedment of silver nanoparticles throughout the whole body of the scaffold. The FT-IR and TOF-SIMS studies clearly identied the strong interaction between the electronegative pyridinic nitrogen of melamine and the electropositive silver cation $( \mathsf { } ^ { + } \mathrm { - } \mathsf { } )$ . The loading of silver increased by 10 times in the presence of melamine. The strong lithiophilicity derived by the heavyloading silver improved the lithium-storage capacity, guaranteeing uniform lithium distribution throughout the scaffold. The narrowing between the neighboring nucleation sites was induced by the lithium-alloyed silver $\left( \mathbf { } _ { x } \mathbf { } _ { y } \right)$ , resulting in the homogeneous lithium nucleation during lithium metal plating. The SEM measurement visualized the even and compact growth of lithium metal along the laminae of the layered carbon frame. Therefore, the reversibility of lithium plating/stripping electrochemistry of the $\mathrm { _ { 1 4 } @ }$ scaffold having the highest lithiophile loading was signicantly improved in four different cell congurations: $\mathbf { _ { 1 4 } } @ \mathbf { } \rVert$ Li, $\mathrm { } _ { 1 4 } @ \mathrm { } \rVert$ Li, $\mathrm { } _ { 1 4 } @ \mathrm { } \| \mathrm { }$ and $\mathrm { } _ { 1 4 } @ \mathrm { } \| \mathbf { O } _ { 2 }$ . Especially, the benet of the $\mathbf { _ { 1 4 } } \mathbf { \textcircled { 2 } } \mathbf { - }$ based lithium electrode on lithium metal battery was demonstrated by the stable capacity retention in $\mathrm { } _ { 1 4 } @ \mathrm { } \| \mathrm { }$ cell $8 1 \%$ at ${ 8 0 0 } ^ { \mathrm { } }$ cycle at 3C) and $\mathrm { } _ { 1 4 } @ \mathrm { } \| \mathbf { O } _ { 2 }$ cell (180 cycle operation at $0 . 2 \mathrm { \ \ ^ { - 2 } }$ ).
