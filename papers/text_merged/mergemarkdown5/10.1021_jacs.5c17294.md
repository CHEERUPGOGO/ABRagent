# Section S1. Materials and Methods

Materials: 2,2,2-trifluoroethyl methacrylate (PTFEMA) and N-methylmethacrylamide (NMMAm) were purchased from Aladdin. Acryloyloxypropyl-functionalized POSS (POSS) was purchased from Macklin. Methacryloyloxy-functionalized $\mathrm { S i O } _ { 2 }$ nanoparticles (20 nm, $\mathrm { S i O } _ { 2 }$ NP) were purchased from 3A Materials. Lithium hexafluorophosphate (LiPF6), fluoroethylene carbonate (FEC), 2,2,2-trifluoroethyl methyl carbonate (FEMC) were purchased from Duoduo chemical company in Suzhou. Azodihetonitrile (ABVN) was purchased from Energy Chemical.

Preparation of GPEs: POSS-GPE and ${ \mathrm { S i O } } _ { 2 } { \mathrm { - G P E } }$ were prepared by in-situ polymerization. First, liquid electrolyte (LE) (1 mol ${ \mathrm { L } } ^ { - 1 } { \mathrm { ~ L i P F } } _ { 6 }$ in FEC/FEMC (3:7 by volume)) was prepared and stirred overnight. Then LE, TFEMA, NMMAm and crosslinker (POSS or SiO2 NPs) were mixed with the weight ratio of m(LE):m(PTFEMA):m(NMMAm):m(cross-linker):m(ABVN) $= ~ 1 0 { : } 0 . 8 { : } 0 . 2 { : } 0 . 1 { : } 0 . 0 1$ . To achieve the gelation of $\mathsf { S i O } _ { 2 } \mathrm { - G P E }$ , pentaerythritol tetraacrylate with the same quality as $\mathrm { S i O } _ { 2 }$ NPs was added to the precursor of ${ \mathrm { S i O } } _ { 2 } { \mathrm { - G P E } }$ . The preparation of electrolyte was conducted in an Ar-filled glove box (Mikrouna, $[ \mathrm { O } _ { 2 } ] < 0 . 0 1$ ppm, $[ \mathrm { H } _ { 2 } \mathrm { O } ] < 0 . 0 1$ ppm).

Preparation of electrodes: The $\mathrm { L i _ { 1 . 2 } N i _ { 0 . 1 3 } C o _ { 0 . 1 3 } M n _ { 0 . 5 4 } O _ { 2 } }$ (LNCMO,7.6 mg $\mathrm { c m } ^ { - 2 } )$ and LiNi0.5Mn1.5O4 (LNMO,8.8 mg $\mathrm { c m } ^ { - 2 } )$ cathodes were fabricated as follows. The active materials, super P and poly(vinylidene fluoride) (PVDF) (8:1:1 by weight) were mixed with N-methyl-2-pyrrolide (NMP). The mixture was casting on Al foil and dried in drying oven for 3 h at $6 0 ~ ^ { \circ } \mathrm { C } .$ then 3 h in vacuum oven at $1 5 0 ~ ^ { \circ } \mathrm { C }$ , 6 h in vacuum oven at $1 5 0 ~ ^ { \circ } \mathrm { C }$ . High loading NCM811 cathode are commercially available and were used after drying in vacuum oven for 3 h at $1 5 0 \mathrm { { } ^ { \circ } C }$ .

Fabrication of batteries: The batteries, pouch cells and 18650 cylindrical cells are fabricated in an Ar-filled glove box (Mikrouna, $[ \mathrm { O } _ { 2 } ] < 0 . 0 1$ ppm, $[ \mathrm { H } _ { 2 } \mathrm { O } ] < 0 . 0 1 \ \mathrm { p p m } )$ .

LIR2032 type coin-cells were fabricated with cathode, lithium metal anode (400 μm and $5 0 ~ \mu \mathrm { m } )$ , Celgard 2500 and precursor solution $( 1 0 0 ~ \mu \mathrm { L } )$ . Then the batteries were kept in a $6 0 ~ ^ { \circ } \mathrm { C }$ oven for 24 h. The 18650 cylindrical cells without electrolytes were provided by Tianjin Plannano Co., Ltd. The 5 Ah pouch cells without electrolytes were provided by Chengdu Yanchuangjuli New Energy Technology Co., Ltd. After injecting precursors, the cells were fabricated and kept in a $6 0 ~ ^ { \circ } \mathrm { C }$ oven for 24 h.

# Section S2. Characterizations and Electrochemical Measurements

Characterizations: Fourier transform infrared spectroscopy (FT-IR) measurements were collected on Thermo Scientific Nicolet iS50. FT-IR spectrometer in the wavelength range of $4 0 0 { \cdot } 4 0 0 0 ~ \mathrm { c m } ^ { - 1 }$ were tested through the attenuated total reflection (ATR) model. The 1H nuclear magnetic resonance (NMR) spectra were measured by a Bruker AV 400 spectrometer at 400 MHz by using chloroform-d as solvent. The tensile test was carried out on UTM6103 mechanical testing instrument (Shenzhen Suns Technology Stock Co., LTD., China) with a tensile speed of $5 ~ \mathrm { m m } ~ \mathrm { m i n } ^ { - 1 }$ . The solidstate NMR spectra were obtained on Bruker AVANCE NEO 400 MHz wide-bore (89 mm) spectrometer at 155.66 Hz (7Li NMR). Raman spectroscopic measurements were tested by WiTec alpha300R confocal Raman microscope. The cycled electrodes were obtained by disassembling the corresponding batteries and washing the electrode with DMC for more than 3 times. Scanning electron microscopy (SEM) was measured on Phenom ProX SEM system. The X-ray photoelectron spectroscopy (XPS) spectra were conducted on Thermo Scientific K-Alpha. The Time-of-flight secondary ion mass spectrometry (ToF-SIMS) were measured by ION-TOF TOF.SIMS5. Transmission electron microscope was measured on JEOL JEM-2100F.

Electrochemical Measurements: The batteries for electrochemical measurements were fabricated by in-situ polymerization methods. All the measurements were carried out at $2 5 ^ { \circ } \mathrm { C }$ if not mentioned. Electrochemical impedance spectroscopy (EIS), Tafel plots and cyclic voltammetry (CV) curves were tested by Vionic (Metrohm). The electrochemical performances of Li||Li, Li||Cu, NCM811||Li, LNCMO||Li, LNMO||Li, NCM811||Gr,

NCM811||Si/C batteries were conducted by LAND battery testing system (Land CT2001A model, Wuhan LAND Electronics.Ltd.) and NEWARE (CT 4008Tn 5V6A S1 F) instruments. The electrochemical floating analysis of NCM811||Li cells were tested by holding at a certain voltage for 10 h. The Tafel plots of Li||Li symmetric cells were measured from −0.25 to 0.25 V with a scanning rate of 1 $\mathrm { m V ~ s ^ { - 1 } }$ . The CV curves of Li||Cu cells were tested in the voltage range of −0.2-2 V with a scanning rate of 1 $\mathrm { m V ~ s ^ { - 1 } }$ .

Calculation of Ionic Conductivity and Activation Energy: The ion conductivities of GPE were conducted by in-situ polymerize precursors between two stainless steels which were separated by thin insulating ring. And the EIS tests were conducted at $0 . 1 { - } 1 0 ^ { 6 }$ Hz, 5 mV. The ionic conductivity (σ) can be calculated by the following equation (1):

$$
\sigma = \mathrm{L} / \mathrm{RS} \tag {1}
$$

where L and S are the thickness and the hole area of the insulating ring, and R is the bulk resistance of the GPE.

The activity energy of $\mathrm { L i ^ { + } }$ transport can be calculated by the following equation (2):

$$
\sigma = \mathrm{A} \exp (- \mathrm{E} _ {\mathrm{a}} / \mathrm{RT}) \tag {2}
$$

Where A is the pre-exponential factor, $\mathrm { E _ { a } }$ is the activation energy of $\mathrm { L i ^ { + } }$ transport, R is the ideal gas constant, and T is temperature.

Calculation of activation energy of $L i ^ { + }$ desolvation process: The activation energy of $\mathrm { L i ^ { + } }$ desolvation process can be calculated by the following equation (3):

$$
1 / \mathrm{R} _ {\mathrm{ct}} = \mathrm{A} \exp (- \mathrm{E} _ {\mathrm{a}} / \mathrm{RT}) \tag {3}
$$

# Section S3. Theoretical Calculation

Density Functional Theory (DFT) Calculations: Binding energies of each molecule were calculated by the DMol3 module in Material studio (MS) 2020. The structure of each molecule was optimized for full relaxation using a generalized gradient approximation (GGA) with a Perdew-Burke-Ernzerhof (PBE) exchange-correlation function. The triple-numeric quality basis set with polarization functions was used. Ionic step convergence was standardized for energy for $1 \times 1 0 ^ { - 5 } \mathrm { H a }$ ，max forces for 0.002 Ha/Å and max displacements for 0.005 Å, respectively. The convergence criterion for the self-consistent field (SCF) is set to $1 0 ^ { - 6 }$ a.u. The binding energy is calculated according to the following formula (4):

$$
\mathrm{E} _ {\mathrm{b}} = \mathrm{E} _ {\text {total}} - \mathrm{E} _ {\text {sub}} - \mathrm{E} _ {\text {abs}} \tag {4}
$$

Where $\mathrm { E _ { t o t a l } }$ is the total energy of both $\mathrm { L i ^ { + } }$ and FEC with polymer matrix, $\mathrm { E _ { s u b } }$ is the energy of individual polymer matrix and $\mathrm { E _ { a b s } }$ are the energy of $\mathrm { L i ^ { + } }$ or FEC.

Molecular Dynamics (MD) Simulations: The solvation structures of POSS-GPE and ${ \mathrm { S i O } } _ { 2 } { \mathrm { - G P E } }$ were investigated by MD Simulations. The simulated system consisted of LE and dispersed POSS, $\mathrm { S i O } _ { 2 }$ NPs with a total atomic number of about 60,000. The OPLS-AA force field was used to characterize the organic electrolyte components and Li⁺ ions, and the ClayFF force field was used to treat the POSS, $\mathrm { S i O } _ { 2 }$ NPs. Van der Waals interactions between the different components were treated by the Lorentz-Berthelot mixing rule. The system was first subjected to a 50,000-step steepest descent method energy minimization to eliminate atomic overlap, followed by equilibration at 303 K for 1 ns under the NVT system, and then transferred to the NPT system for 5 ns to stabilize the system density. To enhance the interaction between Li⁺ and $\mathrm { S i O } _ { 2 }$ NPs, the system was subjected to a high temperature annealing at 600 K for 2 ns followed by a gradient cooling to 303 K. The final production simulation was carried out for 50 ns under the NVT system with a time step of 1 fs, a Velocity-rescale thermoregulator was used to control the temperature, and the Particle Mesh Ewald method was used to handle long-range electrostatic interactions, and the truncation radius was set to 1.2 nm. By analyzing parameters such as the Li⁺ radial distribution function, all simulations were completed using the GROMACS 2019.3 software, and the trajectory data were visualized by the MS software.

# INTRODUCTION

Lithium metal batteries (LMBs) have garnered significant attention for next-generation energy storage, primarily owing to the high theoretical specific capacity (3860 mAh g−1 ), the lowest redox potential (−3.04 V vs the standard hydrogen electrode), and a low density (0.534 $\textrm { g c m } ^ { - 3 } )$ of the lithium metal anode (LMA).1,2 When coupled with high-voltage cathodes, LMBs hold the potential to deliver energy densities of over 500 Wh $ { \mathrm { k g } } ^ { - 1 } . ^ { 3 -  { \hat { 6 } } }$ However, the realization of the application is severely hampered by poor cycle life and safety concerns under practical conditions. -9

Replacing liquid electrolytes with solid-state electrolytes (SSEs) is a prominent strategy to overcome these issues.1 。10 SSEs are commonly classified into inorganic solid electrolytes (ISE) and solid polymer electrolytes (SPEs).11 Compared to the rigid inorganic counterparts, SPEs are particularly attractive for their lower costs, simplified manufacturing, and superior electrode−electrolyte interfacial contact.12 The in situ polymerization further enhances their appeal for large-scale application due to the higher ionic conductivity, improved interfacial contact, and compatibility with current battery fabrication process.13,14 However, polymer electrolytes still suffer from insufficient interfacial stability, leading to short cycle life, especially under practical conditions, such as high capacity, low

negative-to-positive capacity ratio (N/P), and low electrolyteto-capacity ratio (E/C).15,16

Modulating the solvation structure of Li+ can promote the formation of an inorganic-rich cathode electrolyte interphase (CEI) and solid electrolyte interphase (SEI), thereby improving the performance and safety of high-voltage LMBs.17−19 In polymer electrolytes, this modulation can be achieved by engineering the polymer matrix. Motivated by these insights, we focused on siloxanes, a class of widely available and low-cost materials, as building units for the polymer matrix due to their high stability, intrinsic flame retardancy, wide electrochemical window, and weak intermolecular interactions with Li+ . 20−23 Among siloxanes, cagelike polyhedral oligomeric silsesquioxane (POSS) is particularly attractive owing to its rigid structure and facile chemical modification.24−26 Furthermore, the weak interaction with Li+ renders POSS an ideal building block for the polymer matrix to

# RESULTS AND DISCUSSION

# Polymer Structure Design and Characterization

As shown in Scheme 1, the POSS-GPE is fabricated by using an acryloyloxypropyl-functionalized POSS unit as the crosslinker. In the design of the polymer matrix, 2,2,2-trifluoroethyl methacrylate (TFEMA) is selected as the primary monomer to ensure high oxidation stability. Additionally, N-methylmethacrylamide (NMMAm) is incorporated to establish a hydrogen-

bond network, which enhances the mechanical robustness of the polymer electrolyte and its ability to accommodate volume changes of the electrodes during cycling.5 For comparison, methacryloyloxy-functionalized $\mathrm { S i O } _ { 2 }$ nanoparticles (SiO NPs) are selected as the cross-linker to prepare the control $\mathrm { S i O } _ { 2 ^ { - } }$ GPE. The polymerization reactions and the resulting polymer structures of both electrolytes are shown in Figure S1. The in situ polymerization process is detailed in the Supporting Information.

# Electrochemical Performance and Solvation Structure Characterization

The ionic conductivities of both POSS-GPE and ${ \mathrm { S i O } } _ { 2 } – { \mathrm { G P E } }$ are evaluated across the temperature range from 298 to 353 K (Figure S8). POSS-GPE exhibits high ionic conductivity over the entire range (3.04 mS $\mathrm { c m } ^ { - 1 }$ at room temperature) and a low activation energy for ionic migration (11.0 kJ mol−1 ). Crucially, the nearly identical conductivities of the two GPEs indicate that the unique interactions of the POSS units do not impede $\mathrm { L i ^ { + } }$ transport. Furthermore, as shown in Figure S9, electrochemical floating analyses further confirm the excellent oxidation stability of both GPEs, withstanding voltages of up to 4.9 V vs $\mathrm { L i ^ { + } / L i }$ , indicating their stability under high voltages.

To verify the influence of POSS units on the modulation of the solvation structure, the coordination environment of Li+ in both electrolytes is analyzed by molecular dynamics (MD) simulations (Figure S10a-d). The calculated radial distribution function (RDF) and coordination number (CN) are displayed in Figures 1a-b and S10e-f. Notably, POSS-GPE demonstrates

a higher CN for $\mathrm { L i } ^ { + } { - } \mathrm { F } _ { \mathrm { P F } _ { 6 } ^ { - } }$ and a lower CN for $\mathrm { L i ^ { + } { - } O _ { F E C } }$ compared to ${ \mathrm { S i O } } _ { 2 } – { \mathrm { G P E } } .$ . This result confirms that anions preferentially coordinate with Li+ , displacing solvent molecules from the primary solvation sheath and creating the intended anion-rich solvation structure. The simulated solvation structures are then validated experimentally. In 7 Li NMR spectra (Figure 1c), the chemical shift of the POSS-GPE reveals an upfield chemical shift (0.286 ppm) compared to the SiO -GPE (0.371 ppm), suggesting a stronger shielding effect and enhanced Li+ −anion interactions.33 This conclusion is further corroborated by Raman spectra, which reveal a higher proportion of contact ion pairs (CIPs) and reduced solvated FEC molecules in the primary solvation sheath of ${ \mathrm { L i } ^ { + } }$ within the POSS-GPE (Figure S11).34 The modulated anion-rich solvation structure with weakened Li+ −solvent interactions facilitates the desolvation process of Li+ and promotes the formation of a more stable, inorganic-rich SEI.35

Furthermore, electrochemical impedance spectroscopy (EIS) is conducted on Li||Li symmetric cells to probe the desolvation kinetics. Arrhenius fitting of the temperaturedependent EIS data demonstrates a significantly lower activation energy $\left( E _ { \mathrm { a } } \right)$ of desolvation for the POSS-GPE $( - 5 8 . 2 ~ \mathrm { ~ k J ~ } \mathrm { ~ m o l ~ } ^ { - 1 } )$ compared to the ${ \mathrm { S i O } } _ { 2 } – { \mathrm { G P E } }$ (−72.3 kJ mol−1 ) (Figures 1d and S12).36 The lower $E _ { \mathrm { a } }$ indicates a more facile desolvation process for Li+ , which accelerates interfacial charge transfer.18 This assessment is corroborated by a Tafel analysis (Figure 1e). POSS-GPE exhibits a substantially higher exchange current density $\left( { { j } _ { 0 } } \right)$ (0.80 mA cm−2 ) compared to the SiO -GPE (0.46 mA $\mathrm { c m } ^ { - 2 } )$ , indicating improved interfacial kinetics, which is conducive to uniform Li deposition.37

# Electrochemical Performance and Characterization of Electrode−Electrolyte Interphase

To elucidate the influence of solvation structure on the interfacial chemistry between the electrolytes and LMAs, comprehensive analyses of cycled anodes are conducted using scanning electron microscopy (SEM), X-ray photoelectron spectroscopy (XPS), and time-of-flight secondary ion mass spectrometry (ToF-SIMS). On the surface of Li cycled in the POSS-GPE system, Li deposits smoothly and densely, forming a uniform submicrometer-sized spherical morphology with no

evidence of dendritic growth after 50 cycles (Figure 2a-d). This morphology is considered ideal due to the smooth surface and the reduced reactive area between the LMA and the electrolyte.40 This desirable outcome is attributed to the formation of a robust SEI and rapid $\mathrm { L i ^ { + } }$ diffusion kinetics across the interface. In sharp contrast, the surface of cycled Li using $\mathrm { S i O } _ { 2 } .$ -GPE exhibits a loose, porous structure dominated by dendritic and mossy Li (Figure 2e-h), indicating poor interfacial stability and severe parasitic reactions.

XPS analysis is performed to investigate the chemical composition and depth profile of the SEI (Figures 2i-n and S16). In the POSS-GPE system, the F 1s and $\mathring { \mathrm { ~ P ~ } } 2 \mathrm { p }$ spectra of cycled Li show intense and depth-homogeneous signals corresponding to LiF and $\mathrm { L i } _ { x } \mathrm { P O } _ { \nu } \mathrm { F } _ { z }$ which are decomposition products of the $\mathrm { P F } _ { 6 } ^ { - }$ anion.41,42 A prominent $\mathrm { L i } _ { 2 } \mathrm { O }$ peak is observed in the SEI formed on cycled Li within the POSS-GPE system, which facilitates Li+ diffusion through the SEI.43,44 $\mathrm { L i ^ { + } }$ These results confirm the formation of an inorganic-rich SEI driven by an anion-rich solvation structure. In contrast, signals from organic species (such as C�O, $\mathrm { R C O } _ { 2 } \mathrm { L i }$ and $- \bar { \mathrm { C F } } _ { x } ) ,$ , originating from solvent and polymer decomposition, are significantly suppressed. Conversely, the SEI formed on cycled Li in the $\mathrm { S i O } _ { 2 }$ -GPE system is dominated by organic species, with only minor inorganic products originating from anion reduction. 45

This result is further supported by ToF-SIMS analysis (Figures 3f and S23), which reveals a higher concentration of LiF and a lower intensity of organic fragments $\left( \mathbf { C } _ { 2 } \mathbf { H } ^ { - } \right)$ in the CEI of the cycled NCM811 cathode using the POSS-GPE. Critically, the layered structure of NCM811 is well preserved from the surface to the bulk, confirming that the inorganic-rich CEI effectively protects the cathode from parasitic reactions and structural degradation at high voltages. In sharp contrast, the nonuniform CEI formed on the surface of the NCM811 cathode in the control SiO -GPE system fails to provide adequate protection, leading to severe surface reconstruction and the formation of a rock-salt phase after cycling at high voltage.

# Electrochemical Performance and Safety Tests of Practical Cells

To bridge the gap between laboratory research and real-world applications, the performance of the POSS-GPE is systematically evaluated in a series of practical battery configurations under challenging conditions. Full cells with low $\mathrm { N } / \mathrm { P }$ ratios are assembled with high-mass-loading NCM811 cathodes (10.0 and 21.5 mg $\mathsf { c m } ^ { - 2 } \breve { ) }$ and thin Li foil (50 μm). The NCM811| POSS-GPE|Li full cell with an N/P ratio of 5.2 delivers stable cycling with 87.3% capacity retained after 500 cycles (Figure 4a). Even under a lower N/P ratio of 2.5, the NCM811|POSS-GPE|Li full cell still exhibits excellent cycling performance with a capacity retention of 87.3% after 150 cycles, significantly outperforming the control SiO -GPE-based full cell (Figure S24a). Moreover, POSS-GPE can support the stable operation of the full cell with a higher cathode loading of 46.2 mg $\mathrm { c m } ^ { - 2 }$ and a lower N/P ratio of 1.1, as shown in Figure S24b. 22 $S 2 4 \mathbf { \check { b } } . ^ { 2 2 }$ In addition to their attractive electrochemical performance at room temperature, POSS-GPE-based LMBs demonstrate excellent cycling stability at harsh temperatures (Figure S25). At a low temperature of $0 ~ ^ { \circ } \mathrm { C } _ { \mathrm { \lambda } }$ , POSS-GPE exhibits a high ionic conductivity of 1.5 mS cm−1 . As a result, the high-mass-loading NCM811 (10.0 mg cm−2 )|POSS-GPE|Li battery delivers a high discharge capacity of 213.5 mAh $\mathbf { g } ^ { - 1 }$ with stable cycling performance. POSS-GPE also demonstrates excellent electrochemical stability at high temperature, enabling stable operation at 60 ${ } ^ { \circ } \mathrm { C } .$ . This wide temperature tolerance further confirms the practical application prospects of POSS-GPE.

Furthermore, scaled-up high-voltage pouch cells are assembled and evaluated. A 2-Ah NCM811|POSS-GPE|Li pouch cell achieves a cycle life of 100 cycles with 87.6% capacity retention at 4.3 V (Figure 4b-c). The remarkable energy density of 507.2 Wh $\mathbf { k g } ^ { - 1 }$ is successfully achieved in a 5.97-Ah NCM811|POSS-GPE|Li pouch cell operated with a lean electrolyte content $( \mathrm { E } / \mathrm { C } ~ = ~ 1 . 2 6 ~ \mathrm { g } ~ \mathrm { A h } ^ { - 1 } )$ and a high voltage of 4.6 V. This pouch cell demonstrates a cycle life of 50 cycles with 87.4% capacity retention (Figure S26 and Table S2). By optimizing the E/C ratio to 1.40 g $\mathrm { { A h ^ { - 1 } } }$ , both discharge capacity and average discharge voltage are enhanced due to the improved electrode infiltration and reduced polarization. As a result, a superior energy density of 511.2 Wh $\mathbf { k g } ^ { - 1 }$ is achieved, along with an extended cycle life of 70 cycles (Figure 4d-f and Table S2). These results indicate that POSS-GPE achieves the best balance between energy density and cycling performance for polymer-electrolyte-based LMBs (Figure 4g and Table S3).49−5 3 Moreover, the high-energydensity pouch cells also demonstrate exceptional safety by passing the rigorous nail-penetration test without any electrolyte leakage, ignition, or combustion (Figure 4h).

Finally, to demonstrate the versatility and commercial viability of POSS-GPE, industrial-standard solid-state 18650 cylindrical cells are fabricated. An NCM811|POSS-GPE| graphite (Gr) cylindrical cell exhibits excellent rate and cycling performance, retaining 84.8% capacity after 500 cycles (Figure 4i and Table S4). Moreover, a 3.3 Ah cylindrical cell using a Si/C anode also delivers high capacity and stable cycling over 100 cycles (Figure S27 and Table S5), confirming the excellent compatibility of POSS-GPE with commercial anode materials. The outstanding electrochemical performance and safety of both high-energy density pouch cells and industry-standard 18650 cylindrical cells effectively support the practical application potential of POSS-GPE in next-generation highenergy lithium batteries.

# □ CONCLUSION

In summary, a POSS-GPE has been successfully developed by in situ polymerization to improve the cycling performance and safety of high-energy-density LMBs. The POSS-GPE exhibits a high ionic conductivity of 3.04 mS $\mathrm { c m ^ { - 1 } }$ at room temperature, excellent oxidative stability up to 4.9 V vs ${ \mathrm { L i } } ^ { + } / { \mathrm { L i } } ,$ and flame retardancy. The excellent performance of POSS-GPE arises from the ability of POSS units to engineer a desirable anionrich solvation structure, which promotes the formation of robust, inorganic-rich SEI and CEI layers, thereby improving cycling stability. Consequently, POSS-GPE enables the full cell of NCM811|POSS-GPE|Li (50 μm) to achieve a long cycle life of 500 cycles, retaining 87.3% capacity. More importantly, an excellent energy density of 511.2 Wh $\dot { \mathbf { k } } \mathbf { g } ^ { - 1 }$ is achieved in a 6.08 Ah POSS-GPE-based pouch cell $\left( \mathrm { E } / \mathrm { C } = 1 . 4 0 \ \mathrm { g \ A h ^ { - 1 } } \right)$ , which delivers stable cycling for 70 cycles under a high operating voltage of 4.6 V, representing the best balance between cycling performance and energy density for polymer−electrolyte-based LMBs. Therefore, this work demonstrates that high-energydensity and high-safety solid-state LMBs can be achieved through our polymer matrix strategy to modulate the solvation structure in electrolyte systems.
