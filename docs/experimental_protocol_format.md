# 研报实验方法排版规范

参考`docs/示例文档/LiNi0.88Co0.06Mn0.06O2单晶高镍正极材料共混与高电压活化改性及电化学性能研究（第3章）.docx`。示例以“材料制备—电池制作—活化与循环—各类表征”分层，每个方法下连续编号，写清对象、动作、条件与记录项目。研报采用同样的表达形式，内容规模由课题和已有证据决定，不复制示例的配方、测试数据或中试路线。

## 章节与步骤

第5节保留六个模块：实验设计与样品分组、材料制备与极片加工、电池制作与装配、电化学测试与材料表征、数据处理与结果判定、待确认条件与获取方法。

方法使用四级标题，如`#### 5.2.1 粉体合成`；标题下以`1.`、`2.`、`3.`顺序列操作。连续同主题段落合并为一个方法，编号持续递增；不重新排序科学操作。文献依据和适用说明附在对应步骤。没有安排软包或某项表征时，不为了对齐示例增加空栏目或新实验。

Stage 5B在既有调用中生成简短操作段及`step_titles`。旧记录按明确句界和顺序动作只读分步，括号、比例、小数、引用及条件作用域保留；无法可靠概括的主题使用中性方法名。直径的微米到毫米转换只用于显示且严格等值，涂层厚度仍用微米；不通过四舍五入暗改工艺温度。

## 一致性规则

- 第3节方案表是主组材料、配方与固定条件的来源；实验参数通过`ref`读取当前值。对照的变化与目的由`groups[].changes`声明。
- 正式分组表展示样品编号、名称、组别和变量。旧正文中未登记的G组保留名称并标为待确认，不输出与主组引用混写的另一套投料值。
- `{{参数}}=另一数值`的矛盾在新稿进入既有局部修复；旧记录只读渲染时说明冲突并暂停该条操作。相同值的格式重复不视为科学冲突。
- 审核已指出的配方冲突在操作前展示，涉及相应方案字段的方法注明条件待确认；排版不擅自决定哪份配方正确。
- 活化/化成与循环的工况分别保留。保持率基线、工程判据、文献条件和证据限制不得因分步丢失；未执行的实验没有“本章实测结论”。

## 验证和更新

`experiment_protocol.py`为显示层，`experiment_plan.json`、方案表与参数绑定保持原始内容。当前渲染版本为15，报告指纹及终审重算实验正文。纯格式更新只需重生成Stage 6；若旧实验未满足新的需求验证或一致性契约，须先在相应阶段修复实际缺口，不能靠重排正文绕过。

回归覆盖Markdown标题/列表语义、同主题归并、操作顺序、条件与来源保留、等值单位、主对照分组、待确认条件以及终审对正文篡改的检测。
