# 模型计算、声明一致性与正文引用

Stage 4 新设计使用 Writer JSON `version=2`，保留固定五节 `sections`，新增 `parameters` 数值提案。用户锁定和已有非空声明只引用；未锁定空字段可由有依据的工程提案填充。`quantity_kind`、`denominator`、`group_id`、`purpose`、`conditions` 和 `quantity_role` 区分物理量身份。上限、实验封顶和目标分别记录，不因数值不同自动判冲突。

已有输入用 `{{param:cathode.porosity}}` 引用，程序只渲染已登记的值和单位。方案预算由模型写明方法、输入来源、代入、结果/单位、对象/工况及分母，Reviewer独立复核，不再生成或要求 `{{derived:计算ID}}`。计算过程及结果可直接写在正文；下游实际采用的计算结果可登记为普通工程参数，`source`须保留方法与依据，再用param引用。引用仍在参数提取及审核前生成，新提案来源绑定到采用它的完整段落；模型预算不得自称实测或已运行仿真。

实现包括：

- `model_calculations.py`：集中保存计算方法说明和Writer/Reviewer职责，不是公式执行器或固定依赖图。未知输入留缺口，不能从1 C基准电流推断可逆比容量。
- `numeric_consistency.py`：默认只按单位、样品、工况、分母和用途检查数值合法性、同义重复声明、电压窗口及显式上下限，不计算预算、不比较派生公式、不为缺某个规范计算字段阻断。
- `physical_parameters.py`：几何只继承明确声明，不按载量和密度自动补出厚度，不以该换算自动裁决模型计算。`issue_resolution.py`不再依据旧固定链自动结案，原意见与历史记录继续保留。
- `numeric_bindings.py`：只刷新已登记param值。补丁不能删除、新增或更换原始参数引用，显示值须与原值或同次已授权变更一致；旧abr-derived显示保留为历史，不自动重算，授权正文修复可将其替换为模型计算说明。受正文改写影响的工程来源由`source_metadata.py`按唯一原句同步，失效来源通过属性级权限修复；文献和对照的同值数字不全局替换。详见`docs/source_metadata.md`。
- `design_repair.py` / `repair_interfaces.py`：问题按唯一原句授权；显式参数读写、来源及上下限依赖作为事务，Reviewer同时复核各组和合并预览的模型算术与口径。数值改变后旧定位队列失效，沿用现有修复/审核预算，不自动提升原科学审核。

别名只来自显式 `canonical_path` 或有限同义表，例如 `electrolyte.volume_uL`→`electrolyte.volume`。这些映射用于声明一致性、锁定和下游实际参数，不再作为模型计算能否执行的前提。模型必须核对原声明的分母与工况；“正极孔体积”和“全部孔体积”不混用。缺数据或分母为零须明确说明，不能为填预算采用默认值。

生成前，`parameter_names.py`提供简短的常用规范字段表，包含含义、路径和单位；没有已知参数的任务也会收到该表。它不是必填清单，不增加计算链。已有非空值和锁定值只能引用，未锁定null可补充有依据的声明。自定义名称对应表中物理量时须给出`canonical_path`，不同样品或工况继续单列。

返回后按有限别名表核对名称，例如`cathode.total_loading_mg_cm2`关联`cathode.loading_mg_cm2`，保留原字段、原响应、来源和正文引用。规范字段不能通过`canonical_path`改成另一物理量；活性载量与总干涂层载量不能混用。表外未知字段保留，不按相似名称或相同单位猜对应关系。

厚度`L_um`指电极有效层：多孔极片是单面干涂层，致密金属锂负极是锂箔本体。Writer字段表和锂金属专用提示均明确要求`anode.L_um`；明确别名`anode.li_foil_thickness_um`关联此身份，集流体、保护层或复合结构总厚度仍独立。相同组别声明了其他负极材料时拒绝采用锂箔字段，未知材料不由别名推断。几何恢复复用构建器既有的致密锂箔缺省孔隙率0规则，显式孔隙率原样核验、锁定null不回填。报告正文与附录按当前锂金属身份显示“锂箔厚度”。

正文引用、方案表展示、报告参数附录和缺项判断共用`effective_parameters`只读视图：同对象、条件、口径和用途的未锁定空占位可采用唯一有效声明；等值声明合并展示并保留全部来源。不同值、非法单位、锁定null保持待核对；文献、对照和上下限不能填充主方案缺项。采用的同义来源同时进入正文引用依赖，来源值变化使相关科学支持重新核验；不新增计算依赖链。原JSON不被展示逻辑改写。已有报告须重新编译才能采用新视图，不自动提升科学审核。

`ratio_inputs=[分子字段,分母字段]` 可保留为输入来源与修订依赖说明，不触发程序除法或 `calculated.<字段路径>` 结果。比例、质量分数和及预算的算术由模型完成并由Reviewer复核；不能从化学式猜占位，也不能把位点分数或元素系数变化转为总容量损失。Cu/Zn风险排序、上限依据、文献可比性及所有科学结论继续独立审核。

数值审计版本5明确保存 `calculation_policy="model"`，`derived`为空；`CONSISTENT`仅表示所检查的声明和上下限未发现冲突，不表示模型算术已经验证。原值、单位及来源不改写。报告明确披露模型与Reviewer的计算职责，不将“程序未报错”当作计算或科研验证通过。

## 计算方法参考

以下公式仅供模型选择与解释，输入须属于同一样品、工况、分母和质量边界，不要求按表中顺序或固定字段名建立计算链：

| 派生量 | 可用计算路径 |
|---|---|
| 总面载量（mg/cm²） | 干涂层厚度（μm）×压实密度（g/cm³）×0.1；或活性面载量÷活性质量分数 |
| 活性面载量（mg/cm²） | 总面载量×活性质量分数；或同工况面容量÷明确比容量×1000 |
| 压实密度（g/cm³） | 总面载量÷干涂层厚度×10 |
| 干涂层厚度（μm） | 总面载量÷压实密度×10 |
| 活性质量分数 | 活性面载量÷总面载量 |
| 单位面积孔体积（μL/cm²） | 干涂层厚度×孔隙率×0.1；或已声明总孔体积÷极片面积 |
| 总孔体积（μL） | 单位面积孔体积×极片面积；也可沿用已明确声明的总孔体积 |
| 面容量（mAh/cm²） | 活性面载量×明确同工况比容量÷1000 |

例如已声明活性面载量4.5 mg/cm²、质量分数0.80和干涂层厚度25 μm，模型可以在正文写出4.5/0.80=5.625 mg/cm²，及5.625/25×10=2.25 g/cm³，无须先补假设密度或特定规范路径。原稿若仅写含义不清的“极片厚度”，仍须确认是否含铝箔，不自动扣除集流体厚度。

模型应核对不同方法是否相符，说明推算值与实测值的边界，不把同一组输入往返计算当独立验证。历史工具的多路径实现保留在`derived_quantities.py`，仅当显式调用`audit(..., legacy_calculations=True)`或`calculate(..., legacy_calculations=True)`时执行，主流程、方案表更新、门禁及报告均不启用。旧公式及`missing`只是追溯资料，不为当前方案新增必填项。

正文未绑定的量值另记`unbound_mentions`及位置，供Reviewer核对归属；它们可能是模型计算步骤、文献、对照或主方案。未绑定本身不构成错误，不因此降为`INCOMPLETE`，也不自动改值。新增计算方法无需先扩展程序公式表。
